# Eddie Njeru: portfolio

Personal portfolio, live at https://eddie-njeru.vercel.app.

A single static page (`index.html`, with images in `img/`). No build step: Vercel serves the folder as is.
Edit `index.html` and push to `main` to update the site.

Design follows the Edma Systems visual language: ink, paper and gold; Fraunces for headlines and
Archivo for text. Motion is CSS and a little vanilla JS, and all of it switches off for visitors
who ask for reduced motion. Dashboard screenshots are Edma showcase builds with sample data and are
labelled as such.
